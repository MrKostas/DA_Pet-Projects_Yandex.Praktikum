# Прогноз оттока клиентов фитнес-клуба

Как выявить клиентов фитнес-клуба с риском оттока в следующем месяце?

[Открыть ноутбук с расчётами](analysis.ipynb)

## Результат

На проверочной выборке логистическая регрессия выявила 79,2% ушедших клиентов (recall), случайный лес — 71,3%. У регрессии также выше precision: 82,5% против 81,8%. Сегментация выделила две группы с долей оттока 40,2% и 37,3%, для которых предложены разные меры удержания.

## Ход исследования

Данные разделены на обучающую и проверочную выборки 80/20. Логистическая регрессия и случайный лес сопоставлены по accuracy, precision и recall. Для сегментации клиентов построены дендрограмма и пять кластеров KMeans.

**Инструменты** · pandas, scikit-learn, SciPy, seaborn.

## Данные и запуск

Файлы для локального запуска из каталога проекта: `gym_churn.csv`. Поместите их в `data/raw/` в корне портфолио. В ноутбуке сохранены результаты исходного выполнения. Повторный запуск на полном наборе входных данных не проверялся.
