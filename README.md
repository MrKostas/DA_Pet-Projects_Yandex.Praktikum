# Портфолио аналитика данных · Константин Сторожук

Одиннадцать учебных исследований, выполненных в Яндекс Практикуме. В каждой работе доступны постановка задачи, метод и выводы. Таблицы и графики сохранены в ноутбуках, исследование Яндекс.Дзена представлено в формате PDF.

## С чего начать

- **[Окупаемость привлечения пользователей](06-marketing-roi/README.md).** Когортный анализ показывает, почему высокая выручка клиентов из рекламного канала ещё не обеспечивает окупаемость привлечения.
- **[Приоритизация гипотез и A/B-тест](07-online-store-ab/README.md).** Решение по эксперименту основано на сравнении заказов на посетителя и среднего чека, включая проверку устойчивости к выбросам.
- **[Воронка приложения и A/A/B-тест шрифтов](09-app-funnel/README.md).** Анализ журнала событий находит основной спад охвата. A/A/B-тест отдельно проверяет эффект изменения шрифта.

## Локальный запуск

Откройте Jupyter из корня портфолио и запустите нужный ноутбук с рабочей директорией в его папке. Имена входных файлов перечислены в README проектов. Общий каталог для CSV — `data/raw/`. Для проектов 01–03 можно также указать существующий каталог через переменную окружения `PORTFOLIO_DATA_DIR`.

Проекты 01–03 проверены на Python 3.10 с pandas 2.3.3, NumPy 2.2.6, Matplotlib 3.10.9, seaborn 0.13.2 и ipykernel 7.3.0. Для проектов 04–09 и 11 доступны сохранённые результаты исходного выполнения.
