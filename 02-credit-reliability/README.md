# Надёжность заёмщиков

В каких группах заёмщиков чаще встречается задолженность?

[Открыть ноутбук с расчётами](analysis.ipynb)

## Результат

Для автокредитов доля клиентов с задолженностью составила 9,35% (401 из 4 290), для операций с недвижимостью — 7,24% (780 из 10 774). Это сравнение описывает состав выборки и само по себе не устанавливает причину просрочки.

## Ход исследования

Пропущенный доход заполнен медианой по типу занятости. Цели кредитов объединены в категории. Для каждой группы рассчитаны число должников, число клиентов и доля задолженностей.

**Инструменты** · pandas, Matplotlib, seaborn.
