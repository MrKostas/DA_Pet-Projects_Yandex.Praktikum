# Окупаемость привлечения пользователей

Почему реклама Procrastinate Pro+ не окупается, хотя привлечённые пользователи платят?

[Открыть ноутбук с расчётами](analysis.ipynb)

## Результат

На горизонте 14 дней привлечение пользователей из США не окупалось. Канал TipTop приводил пользователей с высокой выручкой, но стоимость их привлечения росла. В работе предложено пересмотреть расходы на этот канал и проверить потенциал Великобритании и Германии.

## Ход исследования

Визиты, заказы и расходы сведены в когорты по дате привлечения. Сопоставлены стоимость привлечения (CAC), накопленная выручка на пользователя (LTV), удержание, конверсия и окупаемость по странам, устройствам и каналам.

**Инструменты** · pandas, NumPy, Matplotlib, seaborn.

## Данные и запуск

Файлы для локального запуска из каталога проекта: `visits_info_short.csv`, `orders_info_short.csv`, `costs_info_short.csv`. Поместите их в `data/raw/` в корне портфолио. В ноутбуке сохранены результаты исходного выполнения. Повторный запуск на полном наборе входных данных не проверялся.
