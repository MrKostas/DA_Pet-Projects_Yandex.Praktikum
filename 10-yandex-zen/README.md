# Просмотры карточек Яндекс.Дзена

Какие темы карточек и возрастные группы дают больше всего просмотров?

[Открыть отчёт (PDF)](report.pdf)

## Результат

Из 310 207 просмотров на десять ведущих тем приходится 55%. «Наука» лидирует в целом с 21 736 просмотрами, тогда как среди пользователей 18–25 лет больше всего просмотров у «Отношений». На эту возрастную группу приходится 43% просмотров ведущей десятки тем.

## Ход исследования

В дашборде Tableau и презентации сопоставлены просмотры по темам карточек и возрасту аудитории. Число созданных карточек проанализировано отдельно по темам источников.
