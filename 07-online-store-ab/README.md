# Приоритизация гипотез и A/B-тест

Какую гипотезу проверить первой и стоит ли принимать вариант B?

[Открыть ноутбук с расчётами](analysis.ipynb)

## Результат

Число заказов на посетителя в B выше на 13,8% на исходной выборке (p = 0,017) и на 17,3% после фильтрации (p = 0,013). Для среднего чека значимых различий не обнаружено. В работе рекомендовано завершить эксперимент в пользу B.

## Ход исследования

Гипотезы ранжированы по ICE и RICE. Для проведённого эксперимента построены кумулятивные метрики. Число заказов на посетителя и средний чек проверены критерием Манна — Уитни до и после исключения аномальных наблюдений.

**Инструменты** · pandas, NumPy, SciPy, Matplotlib.

## Данные и запуск

Файлы для локального запуска из каталога проекта: `hypothesis.csv`, `orders.csv`, `visitors.csv`. Поместите их в `data/raw/` в корне портфолио. В ноутбуке сохранены результаты исходного выполнения. Повторный запуск на полном наборе входных данных не проверялся.
