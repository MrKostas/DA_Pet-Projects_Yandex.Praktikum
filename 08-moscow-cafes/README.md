# Выбор формата кафе в Москве

Какой формат и вместимость выбрать для нового кафе в Москве?

[Открыть ноутбук с расчётами](analysis.ipynb)

## Результат

У кафе в выборке в среднем 39 посадочных мест. Предложен формат независимого кафе на 30–40 мест на Пресненской набережной. Это гипотеза о формате и локации: в данных учитываются действующие заведения, а не их выручка или рентабельность.

## Ход исследования

Заведения сгруппированы по формату и принадлежности к сети. Адреса сопоставлены со справочником улиц для сравнения районов. Отдельно изучены среднее число мест и улицы с высокой концентрацией точек.

**Инструменты** · pandas, Matplotlib, seaborn.

## Данные и запуск
