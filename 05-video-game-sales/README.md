# Продажи видеоигр по регионам

Какие платформы и жанры стоит учитывать при планировании продаж игр?

[Открыть ноутбук с расчётами](analysis.ipynb)

## Результат

В рассматриваемом периоде среди лидеров по продажам в Северной Америке и Европе фигурирует PS4. В Японии лидирует 3DS, а среди жанров выделяются ролевые игры. Единый ассортимент для трёх регионов упустил бы эти различия.

## Ход исследования

Продажи сопоставлены по поколениям консолей, жанрам и регионам. Для планирования выделен период с 2013 года. На отдельных выборках с 2005 года t-тестом Уэлча проверены гипотезы о средних пользовательских оценках.

**Инструменты** · pandas, SciPy, Matplotlib, seaborn.

## Данные и запуск

Файлы для локального запуска из каталога проекта: `games.csv`. Поместите их в `data/raw/` в корне портфолио. В ноутбуке сохранены результаты исходного выполнения. Повторный запуск на полном наборе входных данных не проверялся.
