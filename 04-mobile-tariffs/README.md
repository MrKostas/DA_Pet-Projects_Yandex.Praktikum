# Выручка мобильного оператора

Как сравнить помесячную выручку по тарифам Smart и Ultra?

[Открыть ноутбук с расчётами](analysis.ipynb)

## Результат

В сохранённом расчёте различие между тарифами статистически значимо, а при сравнении Москвы и других регионов p ≈ 0,254. Ограничение расчёта существенно для обоих сравнений: трафик округлён вверх по сессиям до суммирования. По правилам тарифа округлять следует месячный итог. Рекомендация по выбору тарифа требует пересчёта выручки на исходных данных.

## Ход исследования

Данные о звонках, сообщениях и интернет-сессиях объединены по абоненту и месяцу. Для каждого месяца рассчитаны плата за пакет и превышение лимитов. Для сравнения тарифов и регионов применён t-тест Уэлча.

**Инструменты** · pandas, NumPy, SciPy, Matplotlib.

## Данные и запуск

Файлы для локального запуска из каталога проекта: `calls.csv`, `internet.csv`, `messages.csv`, `tariffs.csv`, `users.csv`. Поместите их в `data/raw/` в корне портфолио. В ноутбуке сохранены результаты исходного выполнения. Повторный запуск на полном наборе входных данных не проверялся.
