# Воронка приложения и A/A/B-тест шрифтов

На каком экране теряется аудитория и повлияла ли смена шрифта на поведение?

[Открыть ноутбук с расчётами](analysis.ipynb)

## Результат

Главный экран открыли 7 419 пользователей, экран предложений — 4 593. Это крупнейшее снижение охвата между основными этапами (38,1%). Оплата зарегистрирована у 3 539 пользователей. Статистически значимого эффекта смены шрифта по исследованным событиям не обнаружено. Охваты событий агрегированы и не отслеживают последовательность каждого посетителя.

## Ход исследования

По журналу событий рассчитано число уникальных пользователей на каждом экране. Две контрольные группы сопоставлены между собой, затем экспериментальная группа сопоставлена с контролем с помощью z-теста долей.

**Инструменты** · pandas, SciPy, Plotly, Matplotlib.

## Данные и запуск

Файлы для локального запуска из каталога проекта: `logs_exp.csv`. Поместите их в `data/raw/` в корне портфолио. В ноутбуке сохранены результаты исходного выполнения. Повторный запуск на полном наборе входных данных не проверялся.
